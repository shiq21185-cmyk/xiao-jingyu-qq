总开关

频率上限

太严会让"常驻语音"一聊天就撞墙退文字。现在是每分钟 12 条、每小时 200 条。

语音是怎么发出来的（点开）

她调 qq_say → 桥接调本机常驻 Python worker → 微软 Edge TTS 念成 mp3 → 作为 QQ 语音条发出 → 用完删掉临时文件。

念的话会发到微软的语音服务（edge 引擎要联网）。 想完全不出这台电脑就换成 sapi（Windows 自带，机器味重、中文音色少）。

合成失败、没网、引擎没起时，桥接会当场把同一段文字发出去，所以对方一定收得到。 她返回的 mode 会写明这次走的是 voice 还是 text。

③ 媒体上限（她收得到多大的图）

群里有人发图、发表情，桥接会先把图片抓下来再交给她看。这里控制「多大的图还值得抓」。 超过上限的图会被跳过，她那句就是「（图片总大小超限，已跳过）」—— 也就是看不见这张图。

读取中…

三个上限

默认 8MB / 64MP / 5 张。手机直出的原图常超过 4MB，所以默认比旧版（硬编码 4MB）宽了一倍。

硬天花板：32MB / 256MP / 20 张。填得再大也会被钳到这些值 —— 放宽上限不是拆掉防护，一句配置不能绕过整层校验。

表情包 CDN 兜底

市场表情（从表情商店下载的）常常不在网关缓存里、也没有 url， 网关给不出地址时桥接会靠 emoji_id 推一个 QQ 表情 CDN 地址去取图。 关掉之后那类表情她只能看到一行「[表情#123]」文字。

为什么会有这套上限（点开）

图片要解码才能看，而一张 20000×20000 的「图片炸弹」会直接把内存吃光； 动图几十 MB 也传不动。所以像素和字节都得有阈值 —— 只是阈值可以调。

三个值都会写进 config.json 的 socialV2.media，改完下一张图立刻生效（不需要重启）。

自由时间

你跟她聊完之后，那段没人说话的时间算不算她自己的。算，她就能在那段时间里做空间写操作（发说说、点赞、评论）。 注意：允许不等于必须——那只是"这段时间归她"，不是"该发条说说了"。大部分时候她什么都不做才是对的。

你发完最后一条、接着这么久没再说话，这段就算她自己的。
太短：你还在打字她就拿到自主权（不好）。太长：她基本拿不到（也不好）。
范围 10 秒 ~ 60 分钟。默认 2.5 分钟。

防止"每次聊完她都去发说说"。
填 0 = 不限制（她想写就写）。默认 4 小时，最长 7 天。
⚠️ 它只管写：看空间、翻说说列表不受限制。

这两条规矩她自己也看得见（点开）
她的提示词里写着：静默期只是允许，不是必须；两次空间写之间要隔一段时间（会被执行期拦住，返回 429）； 而且读不受限（想看空间随时看）。所以你在这里调的数字，她那边也大致知道该怎么配合。

等待与超时（她能等多久）

她「等消息」这件事有预算：等太久白烧时间，等太短又老是空手而归。 这里管的是单次等待的上限，以及沉睡前观察要安静多久才算"真的没人说话"。

读取中…

qq_wait_for_messages 一次最多能等多久。默认 10 分钟。
⚠️ 超过 5 分钟的等待走的是另一条通道（node:http）—— Node 自带的 fetch 在 305 秒会强制超时（实测），短于此的等待不受影响。

她没指定时长时用的值。默认 30 秒。

她说"没人说话"之前要安静多久才算数。默认 8 秒。
太短：对方还在打字她就以为聊完了。

为什么超过 5 分钟要换通道（点开）

Node 的全局 fetch 是 undici，它给每个请求自带 300 秒 headersTimeout。实测：一个 320 秒才回头的服务端，全局 fetch 在 305 秒就抛 UND_ERR_HEADERS_TIMEOUT。

所以长轮询改用 node:http（它没有默认响应超时，超时由我们按预算控制）。 不修的话，「他半天不回话」这种最常见的情况，她会以为对方没说话， 实际上是她自己的等待断了 —— 然后重试、撞 429、空转烧 token。

⑥ 现场调试

不想等自然触发时，用这几个直接看效果。

这个控制台为什么是独立的一个进程（点开）

主控制台 public/console.html 是被 git 跟踪的插件文件，更新时整体替换。 本控制台在 tools/extra-console/，自己起一个进程、自己提供页面， 只调用桥接原本就有的几个接口（读配置、写配置、列会话、唤醒）。 所以就算 bridge.js 被换成上游新版，这里的「主动找人」和「现场调试」照样能用。

授权和约定写在 state/ 下，而 state/ 在 .gitignore 里 —— 永远不会被更新碰到。 你的设置和数据都在那儿。

要停它：关掉那个黑窗口，或 Ctrl+C。它停掉不影响小鲸鱼在 QQ 里的任何行为。

需要一次令牌

正常情况下不用管这里 —— 打开页面时令牌已经自动带上了。 只有在你把页面另存到本地打开、或者服务读不到令牌时才需要手填一次。 令牌就是 state/console-token 里那一串。

令牌只存在你自己的浏览器 localStorage 里，不会发给任何人；这个页面也只在本机跑。
