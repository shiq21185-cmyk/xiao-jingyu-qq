## 一、常用手艺

命令都在仓库根目录（`qq-bridge-deploy/`）下敲；`cwd` 不写就是这个目录。

| 他要你干的事 | 敲这一条 | 细节在哪 |
| --- | --- | --- |
| Markdown 转 Word / PDF | `tools\host\.venv\Scripts\python.exe tools\host\md_convert.py "文件.md"` | 加 `--to docx` 或 `--to pdf` 只要一样；`--out-dir` 换输出目录 |
| 把音频转成文字 | `tools\asr\.venv\Scripts\python.exe tools\asr\transcribe.py "音频.wav"` | `--language zh`、`--device cpu`（本机没独显，别用 cuda） |
| 合成一段语音 | `tools\asr\.venv\Scripts\python.exe tools\asr\tts.py "要说的话" --out "out.mp3"` | `--list` 列可用音色；默认 `edge / zh-CN-XiaoyiNeural` |
| 发一条语音到 QQ | `npm run send-voice -- help` 先看用法，再照它发 | **会真的发出去**，先跟主人确认。（详细文档 `guides/VOICE.md` 在本机不存在 —— 被 `.gitignore` 排除了） |
| 把网上的东西（PDF/安装包/压缩包…）发给主人 | 用 `qq_send_file`，`file` 直接给链接（要么给本机路径） | 桥接自己下载 + 校验大小 + 让网关发成文件气泡。**不用先 curl/wget**。默认落在 `桌面\QQ bot\小鲸鱼下载\YYYY-MM-DD\`（`socialV2.file.dir` 可改），上限看 `socialV2.file.maxBytes` |
| 主人要「打好包的」/ 要一堆文件 | 先用 `qq_run_command` 打压缩包，再 `qq_send_file` 发出去 | 例：`command='Compress-Archive -Path "临时打包\\*" -DestinationPath "临时打包\\xxx.zip" -Force'`，`shell='powershell'`；然后 `qq_send_file(file='xxx.zip')` —— 它会自己在下载目录（含各日期袋）里找。**别在 `shell='cmd'` 里写 `powershell -Command "…"`** —— 双层引号会把路径里的反斜杠吃掉（`临时打包\ziptest` 变成 `临时打包ziptest`） |
| 看 QQ 网关通没通 | `node scripts/check-onebot-status.mjs` | 上游心跳字段：`npm run probe:heartbeat` |
| 看桥接活得怎么样 | 浏览器开 `http://127.0.0.1:3100`（桥接自带的控制台） | DSH 侧的工具清单：`npm run probe:tools` |
| 通话相关的排查 | `tools\asr\.venv\Scripts\python.exe tools\call\audio_endpoints.py --list` | 当前通话状态：`tools\asr\.venv\Scripts\python.exe tools\call\call_state.py --json`（`tools/call` 自己没有 venv，借 `tools/asr` 那个） |
| 跑一遍全套离线自检 | `npm run test:audit` | 离线、不发真消息、不用生产凭据。**改完桥接一定要跑一次** |

## 二、动手改过东西之后（顺序别错）

| 你刚改了什么 | 接下来必须做什么 | 为什么 |
| --- | --- | --- |
| 改了 `dsh/agent-presets/` 里的 preset | `node scripts/build-agent-preset-patches.mjs` | patch 是从 preset 源生成的。不重生成，DSH 加载的还是旧的 —— 你会以为改了却没生效 |
| 改了 preset / MCP 工具清单 | 让主人**重启 DSH NEXT** | MCP server 由 DSH 应用级托管，不重启不会重新挂载 |
| 改了 `src/bridge.js` | 让主人重启桥接（或 `npm start`） | 桥接是常驻进程，改文件不会热更新 |
| 准备把东西发到公开仓库 | `npm run privacy-scan` | 扫本机路径 / 凭据泄漏 |
| 记忆库（`state/daily-memory.json`）被修订过 | `node plugins/qq-memory-rollover/qq-memory-rollover.mjs --reindex` | 角色卡上的记忆索引是快照，不重画卡片上还是旧的。`--reindex` 只重画索引，**不调模型、不重写记忆** |
| 改了 `plugins/qq-agent-presets/qq-tool-restrict.mjs`（工具权限分档） | `npm run test:tools`，再让主人**重启 DSH NEXT** | 守卫是 DSH 进程加载的模块，进程里的代码是启动那一刻的 —— 不重启，判定还是旧的那套 |

## 三、出毛病时的第一反应

| 症状 | 敲这一条 |
| --- | --- |
| `state/` 写不进去、沙箱报权限 | `npm run diagnose:acl`，看完再 `npm run harden-acl` |
| 控制台「改模式不生效」 | `npm run probe:protocol` / `npm run probe:settings` |
| 怀疑工具白名单写错了名字 | `npm run scan:tool-names` |
| 新加了个 MCP 工具，怕它默认对群聊开放 | `npm run test:tools` |
| 装 / 重装 DSH 侧挂载 | `node scripts/setup-dsh.mjs`（幂等，可重复跑） |

## 四、三条纪律

1. **只敲这张表里的命令。** 别自己拼 `rm`、`del`、`npm install`、`git push` 这类改动性命令 —— 表里没有就说明这事该先问主人。
2. **别碰这些目录**：`state/`（运行时数据）、`audio/`（主人的语音库）、`roles/`（人格卡）、`config.json`（配置值）。要看可以，别改别删。
3. **跑完把真实输出贴回去**，不要复述命令、不要凭印象说「应该成功了」。命令报错就照原文贴，包括报错信息。

> 这张表只收「主人真会在聊天里让你干的事」。想加一行之前先问自己：他会不会真的要我做这个？
> 会，就加，并且**自己先跑通一次**再写进来 —— 写进来一条跑不通的命令，比不写更坏。
